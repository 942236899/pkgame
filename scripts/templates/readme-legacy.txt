TMH-谁是队友扑克游戏 · 服务器（Windows 7 / Server 2012 R2 兼容版）
================================================================

【一句话】
  解压后双击「TMH-谁是队友服务器.exe」，服务器就起来了。
  不用装 Node、不用装 .NET、不用装任何运行库，绿色免安装。

【用法】
  1. 右键 zip → 全部解压缩（不要只把 exe 拖出来）；
  2. 双击 TMH-谁是队友服务器.exe；
  3. 黑色窗口里会打印访问地址：

         本机访问     http://127.0.0.1:8080
         局域网访问   http://192.168.x.x:8080   ← 发给同桌的人
         网页控制台   http://127.0.0.1:8080/admin

  4. 其他玩家用手机 / 电脑浏览器打开「局域网访问」那个地址即可开局；
  5. 停止服务：按 Ctrl + C，或直接关闭黑色窗口。

【exe 支持的命令行参数】
  TMH-谁是队友服务器.exe                直接开服（双击就是这条）
  TMH-谁是队友服务器.exe --port 18080   换一个端口开服
  TMH-谁是队友服务器.exe --open         开服并自动打开网页控制台
  TMH-谁是队友服务器.exe --stop         停止正在运行的服务器
  TMH-谁是队友服务器.exe --check        检查文件是否齐全（排障用）
  TMH-谁是队友服务器.exe --help         查看帮助

【目录里每个文件是干什么的】
  TMH-谁是队友服务器.exe   启动器（原生程序，1.6MB）
  runtime\node.exe         JavaScript 运行时（Node 18，自带）
  server\                  服务端代码
  web\                     网页版游戏（玩家浏览器打开的就是它）
  config.json              端口 / MySQL 配置，记事本可直接改
  ★ 启动服务器.bat          功能菜单（放行防火墙、开机自启、查看 IP 等）

  注意：exe、runtime、server、web 必须在同一个目录里，少一个都启动不了。
  想换电脑或换目录：把整个文件夹一起拷走即可。

【为什么原来那个服务端 exe 打不开】
  原来的服务端 exe 是用 Electron 44（Chromium 内核）打包的。
  Electron 从 23 版开始就不再支持 Windows 7 / 8 / 8.1 内核，
  而 Windows Server 2012 R2 的内核正是 Windows 8.1，所以双击会弹：

      此应用无法在你的电脑上运行。
      若要找到适用于你的电脑的版本，请与软件发布者联系。

  这不是文件没拷全，也不是缺 dll —— Chromium 的二进制文件本身
  在老系统上就无法加载，补任何运行库都没用。

【这个版本为什么能跑】
  服务器程序（Express + WebSocket）根本不需要浏览器内核，只认 JS 运行时。
  所以这里的 exe 是一个极小的原生启动器，真正干活的是：

    · runtime\node.exe —— Node 18，最后一个官方支持 Win8.1 / 2012 R2 的 LTS
    · 不写注册表、不装服务、不依赖 .NET / VC++ / Chromium
    · 功能与原版完全一致：开房、联机、记牌、MySQL 落库、网页控制台
    · 前端 gzip 压缩 + WebSocket 压缩，1Mbps 外网也能流畅联机

【常见问题】
  · 双击后窗口一闪而过：exe 出错时会停住等回车，可截图发给开发者；
  · 提示端口被占用：说明已经开着一个了，或被别的程序占了，用 --port 换一个；
  · 提示缺少 runtime\node.exe：解压不完整，重新完整解压一次；
  · 别人连不上：先用「★ 启动服务器.bat」菜单 5 放行防火墙；
  · 公网访问：需要在路由器做端口映射，或云服务器安全组放行端口。

【关于客户端】
  老系统上不要用那个 Electron 客户端 exe，同样跑不起来。
  直接用浏览器访问服务器地址即可，手机、平板、电脑功能完全一样。

详细说明见同目录 使用说明.html。
