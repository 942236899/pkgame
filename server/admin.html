运维提示

· 改端口：在上面的「服务器设置」里改 → 保存 → 重启服务器（或直接改 server\config.json）
· 局域网：手机与本机连同一个 Wi-Fi，访问上面的局域网地址
· 公网：把端口映射到公网（路由器端口转发 / 云服务器安全组放行），用 http://公网IP:端口 访问
· 停止服务：点上面的「停止服务器」，或在启动它的黑窗口里按 Ctrl+C，或直接关闭窗口
· 开机自启：用解压目录里的「设置开机自启.bat」（需要管理员权限）
