# TMH-谁是队友扑克游戏

4 人扑克（52 张、无大小王）。**一套代码，四种交付形态：网页 / Windows exe / 安卓 APK / iOS APP。**

> **玩家 / 运维请看：[`发布/使用说明.html`](发布/使用说明.html)**（本地畅玩、局域网开房、公网部署上线、控制台、MySQL、客户端连接、规则速查、常见问题）。
> 本 README 面向开发者与二次开发。

## 一、玩法规则（最终版）

| 项目    | 规则                                                                                                                                |
| ----- | --------------------------------------------------------------------------------------------------------------------------------- |
| 用牌    | 一副去掉大小王，4 人各 13 张                                                                                                                 |
| 点数    | `4 < 5 < 6 < 7 < 8 < 9 < 10 < J < Q < K < A < 2 < 3`                                                                              |
| 花色    | `♦ 方块 > ♠ 葵扇 > ♥ 红桃 > ♣ 梅花`（同点数时比花色）                                                                                              |
| 牌型    | 单张 / 对子 / 纯 3 张 / 顺子（5 张，`34567` 最小、`10JQKA` 最大，2 不参与）/ 同花（5 张同花色，点数任意）/ 三带二 / 四带一 / 同花顺（5 张同花色且连续，`♣34567` 最小、`♦10JQKA` 最大）      |
| 压制    | **同牌型才能压同牌型**，一直压到该牌型的最大牌出现、无人能压为止。<br />单张→单张，对子→对子，纯3张→纯3张，5张组合→5张组合（**同花顺 > 四带一 > 三带二 > 同花 > 顺子**）                             |
| 同花比大小 | 默认**先比牌面**：从最大的一张开始逐张比点数，点数序列完全相同才比花色。<br />设置里可切换为**先比花色**（♦ > ♠ > ♥ > ♣），同花色再逐张比点数                                              |
| 首出    | 没有规定，**每局抽签（随机）决定**，开局会提示是谁                                                                                                       |
| 纯 3 张 | 只能在「自由出牌」时打：① 开局第一个出牌的人手上正好有；② 其余 3 人全部过牌、牌权回到你重新出牌时。跟牌压制不能出                                                                      |
| 找队友   | ♦A 与 ♦3 的持有者**自动成为队友**，另外两人自动成另一队                                                                                                 |
| 暗置    | 只打出其中一张（♦A 或 ♦3）时，另一名队友自己心里知道就行，**系统不做任何标注、不提示、不回应**                                                                              |
| 公开时机  | **♦A 与 ♦3 都打出来了**才由系统公开标明：<br />· 两人分别打出 ⇒ 这两人是队友，另两人自动成另一队<br />· 两张都从同一人打出 ⇒ 他是独狼，标明**另外 3 人**一队（1 打 3）<br />若到本局结束仍没全出，结算时同样公开 |
| 撞车    | ♦A 与 ♦3 落在同一个人手里 ⇒ 他**没有队友，1 打 3**（独狼）。是否宣告由他本人私下决定（宣告进贡 3 张，不宣告 2 张）                                                             |
| 计分    | **只公布输赢，不计分**。结算显示本方胜/负与累计胜场、负场，没有积分、等级、金币                                                                                        |

**结算进贡**（下一局发牌后执行）

- 队友拿 1、2 名 → 输方各进贡 2 张最大的牌，赢方各回 2 张
- 队友拿 1、3 名 → 输方各进贡 1 张，赢方各回 1 张
- 1、4 名 或 2、3 名 → 平局，不进贡
- 独狼拿第 1 名算赢：另外 3 人各进贡（宣告 3 张 / 未宣告 2 张）；没拿第 1 名算输，方向反过来
- **3 不参与进贡**：交「最大的牌」时最大只交到 **♦2**，手里的 3 一律保留；只有除 3 以外的牌不够数（同一人累计要交 6 张 / 9 张）时，才先用 ♣3 补，♦3 留到最后

## 三、最快上手

```bash
node server/index.js             # 起服务器，默认 8080
```

浏览器打开 `http://127.0.0.1:8080`。控制台会打印局域网地址，同一 Wi-Fi 的手机直接访问即可。  
控制台页面：`http://127.0.0.1:8080/admin`

也可以直接双击根目录的 **`启动服务器.bat`**（起服务 + 自动开浏览器）。

## 四、四种交付形态

### 1. 网页（全平台通用，iOS 推荐用这个）

就是 `server/index.js` 托管的页面，也是其余三端的源码。局域网 / 公网都能部署（见第六节）。

- **网页进入**：主菜单 →「网页进入 · 手机扫码」，生成当前地址的二维码（本地生成，不依赖 CDN），手机扫码即玩；房间里点「扫码进房」可带房间码直接入座。桌面客户端会自动把 `127.0.0.1` 换成局域网 IP。
- **添加到主屏幕**：带 `manifest.webmanifest` + 180/192/512 图标，iPhone Safari「添加到主屏幕」后全屏运行，和原生 App 体验接近。
- **响应式**：320 / 360 / 430 / 560 / 820 / 1200 / 1600 分档缩放，手牌自动叠放（13 张始终一屏），横屏紧凑模式，刘海屏安全区适配。

### 2. Windows exe（免安装绿色版）

| 产物         | 路径                               | 用途                                                                   |
| ---------- | -------------------------------- | -------------------------------------------------------------------- |
| **游戏客户端**  | `发布/TMH-谁是队友/TMH-谁是队友.exe`       | 双击即玩。自动启动内置服务器，本身是房主；菜单里有「局域网地址 / 复制邀请地址 / 服务器控制台 / MySQL 状态 / 游戏规则」。Electron，要求 Win10 / Server 2016+ |
| **服务端窗口** | `发布/TMH-谁是队友服务器/TMH-谁是队友服务器.exe` | **原生 Windows 图形窗口**：启动/停止服务器、端口、监听地址、MySQL、实时日志、在线人数。打开即自动开服，关窗即停服。Win7 SP1 / Server 2012 R2 起都能跑 |

```bash
npm run exe          # 客户端 + 服务端一起打
npm run exe:client   # 只打游戏客户端（Electron）
npm run exe:server   # 只打服务端（Go 图形窗口 + Node 18 运行时）
```

### 3. 安卓 APP

```bash
npm run android      # 一键：装 JDK21/Android SDK/Gradle → 同步资源 → 出 APK
```

产物：`发布/TMH-谁是队友-Android.apk`（debug 版，可直接装）。  
首次构建会自动下载约 800MB 的工具链到 `.tools/`（走国内镜像，几分钟）。  
出正式签名包：`npm run android:release`（需先在 `android/app/build.gradle` 配签名）。

### 4. iOS APP（需 macOS + Xcode）

Windows 上只能准备工程，编译必须 macOS：

```bash
npm run ios          # 同步网页资源到 ios/ 工程
```

然后把整个项目拷到 Mac：

```bash
cd ios/App && pod install
open App.xcworkspace
# Xcode：选开发者账号 → Product → Archive → Distribute App
```

> 没有 Mac 也能让朋友的 iPhone 玩：用 Safari 打开服务器地址，「添加到主屏幕」，体验和原生 App 几乎一致（游戏本身就是响应式网页）。

### 5. 服务端图形窗口（原生 Win32，Win7 / Server 2012 R2 起）

服务端早期是 Electron 做的控制台，而 Electron 23 起放弃 Windows 7 / 8 / 8.1 内核，**Server 2012 R2 的内核就是 8.1**，双击会报「此应用无法在你的电脑上运行」。服务端本身只是 Express + ws，根本不需要 Chromium，所以 1.3.0 起换成原生窗口：

```bash
node scripts/build-server.js            # 产物：发布/TMH-谁是队友服务器/ + -Windows服务端.zip
                                        #      + -Win2012兼容版/ + .zip（内容相同，兼容旧名字）
                                        # 需要 .cache/go 下的 Go 1.21 工具链编译 GUI
```

- 窗口源码 `tools/gui/main.go`：纯 Win32（user32 / gdi32 / kernel32 syscall），`-H windowsgui` 编译后**没有控制台**。
- 它用 `CREATE_NO_WINDOW` + `HideWindow` 拉起 `runtime\node.exe server\cli.js`，stdout/stderr 通过管道回传窗口的日志区。
- 停止走 `POST /api/shutdown` 优雅退出，4 秒未退才 `Process.Kill()`；关窗同样会先停子进程，不留孤儿 node.exe。
- `--selftest` 无界面自检（起服 → 查 `/api/status` → 停服），构建脚本与 CI 可直接用。

| 组成 | 说明 |
| --- | --- |
| `TMH-谁是队友服务器.exe` | 原生 Win32 图形窗口（约 5MB），启停 / 端口 / 监听地址 / MySQL / 日志 / 在线统计 |
| `runtime/node.exe` | Node **18.20.8**（最后一个官方支持 Win8.1 / Server 2012 R2 的 LTS），绿色免安装 |
| `server/` `web/` | 服务端代码 + 网页版游戏 |
| `config.json` | 端口、监听地址、autoOpen、MySQL；窗口里的「保存设置」就写这里 |
| `启动服务器.bat` / `停止服务器.bat` / `打开游戏页面.bat` | 窗口没反应时的兜底：拉起 exe / 强制停服 / 直接开浏览器 |
| `/admin` | 网页版控制台：房间、实时日志、改端口、停止服务（ES5 写法，IE11 也能打开） |

老系统上**不要**再用 Electron 客户端，所有玩家用浏览器访问服务器地址即可，功能一致。

## 五、数据库：MySQL

配置在 `server/config.json`（或控制台网页里填写）：

```json
{ "db": { "enabled": true, "host": "127.0.0.1", "port": 3306,
          "user": "root", "password": "", "database": "tmh_poker" } }
```

```bash
mysql -u root -p < schema.sql
```

表：`player`（玩家）、`game`（牌局）、`game_seat`（座位/队伍/名次）、`game_action`（逐手出牌，可复盘）。  
**连不上 MySQL 时自动降级为内存模式，游戏照常进行，只是不落库。**

## 六、服务器部署：局域网 / 公网

服务器默认 `host: 0.0.0.0`、`port: 8080`，在服务器窗口里改，或直接编辑 `server/config.json`（发布包根目录的 `config.json` 同源）。

**局域网（家里 / 办公室）**

1. 双击 `TMH-谁是队友服务器.exe`，窗口里点「▶ 启动服务器」
2. 窗口「局域网访问」一行显示 `http://192.168.x.x:8080`，点「复制」发人
3. 手机连同一 Wi-Fi，用浏览器或安卓 APK 打开这个地址

**公网（朋友在外地）**

- 云服务器：把整个 `server/` + `dist/`（或整个项目）传上去，`node server/index.js`，安全组放行 8080
- 家里宽带：路由器做端口转发（外网 8080 → 内网某台机器 8080），或用 frp / 花生壳内网穿透
- 邀请链接形如 `http://你的地址:8080/?server=http://你的地址:8080&room=ABCD`，好友点开直接进房

**静态资源只暴露** `index.html`、`/css`、`/js`，源码与 `package.json` 一律 404。

### v1.4.2（2026-10-20）

**手机端响应式 + 摸牌手感**（`css/style.css`、`js/ui.js`、`index.html`）：

- **倒计时不再挡玩家信息**：`.seat .turn-timer` 从「名牌旁边、朝牌桌中央那一侧」改到**出牌者头像上**（`position:absolute` 在 `.av` 内，`width:calc(100% + 7px)`），头像位置一圈读秒环 + 中间秒数。手机牌桌窄时不再顶到对家名牌、不再压住中央提示。`tt-in/tt-beat` 改名为带 `translate(-50%,-50%)` 的 `tt-in-c`，`.my-timer` 单独保留原 `tt-in`。
- **中央提示换位**：竖屏 `.felt-tip { top:28%; max-width:66% }`（落在对家名牌与左右两家名牌之间的空档）；横屏 `top:50%; max-width:38%` + 单行省略。
- **横幅贴底栏**：`#turnBanner` 移进 `.bottom`，改成 `position:absolute; bottom:calc(100% + 8px)` —— 永远压不到手牌 / 我 / 张数；`UI.flashTurn()` 清 toast、`UI.toast()` 收横幅，两者不叠。
- **toast 位置**：`bottom: calc(var(--ch) + var(--lift) + 96px + var(--safe-b))`，矮屏不再跳到顶栏上。
- **划选手感（重写 `UI.bindSwipeSelect`）**
  - `.hand { touch-action:none }`：浏览器不再把手势当滚动，拖选不会被 `pointercancel` 打断。
  - 落点改成**按横向坐标几何判定**（`indexAt()` 遍历按下时缓存的 `getBoundingClientRect`），替掉 `elementFromPoint` —— 拇指竖向飘移不再断选，牌抬起 18px 也不会串到邻牌。
  - `setPointerCapture`：划出手牌区继续选；只在跨过 9 像素后才 `applyRange`，且下标没变不重绘。
  - 单击 / 拖动都加 `navigator.vibrate(8)` 轻震。
- **选中抬起不被裁**：新增 `--lift` 变量（默认 18px，`max-height:560` 11px，矮横屏 13px），`.hand-wrap` 高度改成 `calc(var(--ch) + var(--lift) + 12px)`；`.hand .card.sel` 用 `translateY(calc(var(--lift) * -1))`。
- **长昵称防溢出**：`.mybar .me-nm` 加 `max-width:34vw` + 省略号，`.my-timer { flex:0 0 auto }`。
- 测试：`smoke.js` 划选用 `getBoundingClientRect` 假尺子（不再 mock `elementFromPoint`），新增 5 项断言（倒计时在头像内 / 昵称张数还在 / 横幅与 toast 互斥），共 156 项。

### v1.4.1（2026-10-20）

**服务端窗口（Go + Win32）三个问题修复**：

- **「启用 MySQL 记录对局」勾不上 —— 根因与修复**
  - 该复选框创建时用的是 `BS_AUTOCHECKBOX|BS_OWNERDRAW`。按钮类型只取 `BS_TYPEMASK`（低 4 位），`0x03|0x0B == 0x0B`，**实际类型只剩 `BS_OWNERDRAW`**，Windows 不再把它当复选框：点击不自动翻转、`BM_SETCHECK` 写不进去、`BM_GETCHECK` 永远返回 0。
  - 修复：勾选状态改由程序自己维护（`checkState` map，`tools/gui/main.go`），点击后翻转并立即 `InvalidateRect` 重画；绘制端 `drawCheck()` 也改为读自己的状态，不再依赖 `ODS_CHECKED`（该位按文档只用于菜单项）。
- **MySQL 五项填不了**：去掉「未启用就 `EnableWindow(false)` 整组变灰」的旧逻辑，改为**始终可编辑**；「启用」只决定用不用。`idDbNote` 提示随勾选在「已启用 / 未启用」之间切换。保存后写入 exe 同目录 `config.json`，下次启动自动读回。
- **点 ✕ 直接退出**：改为先弹二次确认（运行中会提示停服后果），确认后才停服退出。
- **最小化收进托盘**：`WM_SYSCOMMAND / SC_MINIMIZE` 拦截后隐藏窗口 + 移除任务栏按钮（`WS_EX_TOOLWINDOW`），`Shell_NotifyIconW` 加托盘图标；双击图标或右键菜单可「打开主界面 / 启动服务器 / 停止服务器 / 退出」。
- **日志上下拉动文字重叠变黑**：只读 EDIT 发出的是 `WM_CTLCOLORSTATIC`（不是 `WM_CTLCOLOREDIT`），旧代码一并走了静态文字的 `TRANSPARENT` 背景模式，滚动时系统只重画字形不擦底色。现在 EDIT 一律 `OPAQUE + SetBkColor`，每行先铺底再写字。

验证：脚本化驱动真实 exe，点复选框 → 提示由「未启用」变「已启用」；填五项 → 点保存 → `config.json` 里 `db.enabled: true` 且 host/port/user/password/database 全部落盘；重启 exe 能读回 `enabled: true`。

**独狼模式：名次改成「独狼定名次、其余并列」+ 进贡张数查表 + 开局可「直接下一局」**（四端同一套 `js/engine.js`，服务端直接复用）：
